Side Menu

Per-product navigation panel, 280px, flush to the left edge. Hidden by default; hovering the Top Bar toggle peeks it as an elevated overlay, clicking pins it (content with .side-menu-offset shifts; below 768px it stays an overlay with a scrim). Header locked to the Top Bar height · 32px search · collapsible groups · optional .side-menu__divider before secondary navigation · pinned user footer with an upward menu. Behaviour from navigation.js; group collapsing is pure CSS (aria-expanded). Live pin / peek: prototypes/unified-navigation.html.

Static — .side-menu--static (groups collapse, items select, user menu opens)
Content Management

In a real page the menu is a fixed <aside class="side-menu" id="side-menu" tabindex="-1"> next to a .top-bar with a .top-bar__toggle; add .side-menu__close (keyboard-only close) inside .side-menu__actions and a .side-menu-scrim for mobile. Selecting an item fires side-menu:select.
